## Format

Each ADR follows this structure:

```markdown
# ADR NNNN: Title

## Status
Accepted | Proposed | Deprecated | Superseded

## Context
What is the issue we're addressing?

## Decision
What is the change we're making?

## Consequences
What are the trade-offs, positive and negative?
```
